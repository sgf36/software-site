Spencer Fields によるソフトウェア

ひとつの仕事をきちんとこなす、小さなツールたち。

英国で設計・開発された独立系ソフトウェア。それぞれは、既存のツールが必要以上に手間のかかるものにしていた作業から生まれたもので、各製品は独自の名前のもと、独自の利用規約、価格、プライバシーポリシーで公開されています。

ソフトウェアについて

デスクトップとモバイルにまたがる3つのアプリケーション。それぞれに詳細、価格、利用規約を掲載した専用サイトがあります。

  • 提供中

    Easy-Post Desktop

    コードやブラウザのダッシュボードではなく、ご自身のEasyPostアカウントで動作する本格的なデスクトップアプリケーションから、各配送業者のリアルタイム料金を比較し、ラベルを購入・印刷し、荷物を追跡できます。

    Windows および macOS ・ Microsoft Storeでも入手可能

    easy-post.spencerfields.com

  • Androidで提供開始

    Easy-Post モバイルコンパニオン

    Easy-Post Desktopと連携する、スマートフォン向けの配送追跡アプリ。Google Playへの掲載準備中のため、Android版は署名済みの直接ダウンロードとして提供中。iPhone版はApp Storeへの登録準備を進めています。

    Android および iOS

    easy-post.spencerfields.com/mobile

  • 審査中

    Wren

    人々がすすめる場所を、Apple Mapsのガイドに変換します。スクリーンショットから読み取ったり、ファイルからインポートしたり、すでにお持ちのガイドに追加したりできます。App Storeに提出済みで、審査を待っています。

    iPhone、iOS 18以降・47言語

    wren.spencerfields.com

これらの作り方

この3つのアプリケーションは製品としての共通点はほとんどありませんが、いくつかの同じ原則に基づいて作られています。

データはお客様のものです。Easy-Post Desktopはデータをお使いのマシンに保存し、お客様ご自身のEasyPostアカウントに対して動作します。アナリティクスもテレメトリーもありません。Wrenにはアカウントもサインインもなく、スクリーンショットはデバイス上で読み取られ、アップロードされることは一切ありません。各アプリケーションは、デバイスから何がどのような理由で送信されるかを明確に記載したプライバシーポリシーを公開しています。

ネイティブであり、見せかけのブラウザではありません。Easy-Post DesktopはWindowsとmacOS向けの本物のデスクトップアプリケーションです。Wrenは本物のiPhoneアプリケーションです。どちらも、動作するプラットフォームのために作られています。

率直に語ります。各ウェブサイトでは、アプリケーションにできることと同じくらい率直に、できないことも説明しています——プラットフォームが妨げとなる部分、実際に存在する制約、そしてほかの誰かの対応を待っている部分です。WrenのソースコードはGitHubで公開されています。

広く使われる言葉で。Wrenは47言語に翻訳されており、両方の製品サイトは世界で最も話者数の多い15言語で公開されています。

事業について

Spencer Fieldsは英国で設立された個人事業主で、自身の名義で事業を営んでいます。購入手続きは各エディションの販売元または販売代行事業者が行います。Easy-Post DesktopのMicrosoft Store版はMicrosoft、直接ダウンロード版はPaddle、App Store経由で購入したものはすべてAppleが担当するため、支払い情報が当事業者に渡ることはありません。
