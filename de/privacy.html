Keine Analysetools, keine Cookies, kein Tracking

Diese Website verwendet keine Analysedienste, setzt keine Cookies und lädt keine Skripte, Schriftarten oder Bilder von Drittanbietern. Jede Seite ist in sich geschlossen: Nichts auf ihr stellt eine Anfrage an einen anderen Server als diesen. Dies ist bewusst so gestaltet, und jede Änderung daran würde an dieser Stelle vermerkt werden.

Das Kontaktformular

Wenn Sie über das Kontaktformular eine Nachricht senden, werden folgende Daten erfasst:

  • Ihr Name und Ihre E-Mail-Adresse, damit die Nachricht beantwortet werden kann.
  • Das von Ihnen gewählte Thema und die von Ihnen verfasste Nachricht.
  • Ihre IP-Adresse, die ausschließlich zur Begrenzung der Anfragerate verwendet wird (um zu verhindern, dass das Formular zum massenhaften Versand von Nachrichten missbraucht wird). Sie wird vorübergehend gespeichert und innerhalb einer Stunde gelöscht.

Die Nachricht wird über einen Cloudflare-Worker-Relay an Apps@spencerfields.com zugestellt, mit einem direkten Serverversand als Ausweichlösung. Die Nachricht wird von Spencer Fields gelesen und zur Beantwortung verwendet. Sie wird an niemanden sonst weitergegeben, nicht für Marketingzwecke genutzt und keiner Mailingliste hinzugefügt.

Das Formular erfasst außerdem einen Zeitstempel (Zeitpunkt des Seitenaufrufs) und prüft ein verstecktes Feld, um eine von einem Menschen eingegebene Nachricht von einer automatisiert eingereichten Nachricht zu unterscheiden. Keines dieser beiden Elemente stellt personenbezogene Daten dar.

Server-Zugriffsprotokolle

Der Hosting-Anbieter führt übliche Zugriffsprotokolle, in denen die IP-Adresse, die Browserkennung und die von jedem Besucher angeforderten Seiten erfasst werden. Dies ist bei jedem Webserver Standard und wird von diesem Unternehmen weder eingesehen noch ausgewertet oder über die eigene Aufbewahrungsfrist des Hosting-Anbieters hinaus gespeichert.
