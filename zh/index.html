Spencer Fields 出品的软件

专注把一件事做好的小工具。

在英国设计和开发的独立软件。每一款都源于一项被现有工具弄得比本该更麻烦的任务，并且各自以自己的名称发布，拥有各自的条款、定价和隐私政策。

软件

这些是如何开发的

这三款应用作为产品彼此差异很大，但都遵循同样几条准则来打造。

您的数据始终归您所有。Easy-Post Desktop 将数据存储在您自己的电脑上,并直接对接您自己的 EasyPost 账户;它没有任何分析或遥测功能。Wren 没有账户、无需登录,只在设备本地读取您的截图,绝不上传。每款应用都发布了隐私政策,清楚说明有哪些内容会离开您的设备,以及原因。

原生开发,而非伪装的浏览器。Easy-Post Desktop 是一款面向 Windows 和 macOS 的真正桌面应用。Wren 是一款真正的 iPhone 应用。两者都是针对其运行平台专门打造的。

坦诚说明。各产品网站会同样清楚地说明每款应用做不到什么,而不只是能做什么——包括平台带来的限制、真实存在的局限,以及仍需其他人配合才能实现的部分。Wren 的源代码已发布在 GitHub 上。

广泛支持多语言。Wren 已翻译成 47 种语言,两个产品网站也都提供了全球使用人数最多的十五种语言版本。
